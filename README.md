# 畲韵奇旅 · 从一件凤凰装，读懂一个民族

以畲族服饰为入口的年轻化文化项目。从福建宁德出发，走访中华畲族宫、上金贝与半月里，用凤凰装、凤冠与彩带，把山哈的审美讲给同龄人听。

纯静态单页网站，无框架、无外部依赖，直接用浏览器打开 `index.html` 即可。

## 目录

```
index.html    完整页面（HTML + CSS + JS 内联，单文件）
p1 ~ p14.jpg  页面配图
```

## 图片来源

页面照片为实地走访拍摄，原始高清文件未随仓库提供，仓库内为网页适配版本
（长边压缩至 2000px、JPEG 质量 85），原始文件约 102 MB，压缩后约 7.8 MB。

## 本地预览

```bash
python -m http.server 8090
# 浏览器打开 http://localhost:8090
```

> 注意：直接双击 `index.html` 也能正常查看，但个别浏览器在 `file://` 协议下
> 对本地图片有读取限制，用上面的静态服务更稳妥。
